# images/calendar — 行事曆產生器的月份標題圖

每個月一組，共 12 個月 × 2 款＝24 張。兩款是**使用者各自排版好的兩套來源檔**，
不是互相壓縮出來的。

| 檔名 | 尺寸 | 用途 | 目前進度 |
|---|---|---|---|
| `title-MM.webp` | 高 300px（寬約 1210～1310） | 標準版，兩行字＋右側合照 | 1～12 月 ✅ |
| `title-MM-slim.webp` | 高 222px（寬約 1480～1520） | 壓扁長條版，一行字 | 1～8 月，其餘待補 |

`MM` 是兩位數月份（`01`～`12`）。

## 這些檔的處理規則

- 去背透明底（PNG 的 alpha 保留成 webp 的 alpha）。
- 四周透明邊全部裁掉，**底部裁到文字最底**——右邊那張母女合照原本比文字低一截，
  超出的下半身一起切掉，所以整排底部是齊平的，直接貼在版面上不會有落差。
- **對齊高度而不是寬度**：每個月只有數字不同，左邊界會差幾十像素；若統一寬度，
  12 個月的「團購行事曆」會一個月比一個月大一點點。統一高度後字級完全一致，
  寬度那 3% 的差交給版面靠左或置中處理。
- webp quality 92（有文字邊緣，壓太狠會糊）。
- 標準版 300px、壓扁版 222px 這兩個高度不是隨便挑的：兩套來源檔裁切後分別是
  305 / 226px，用同一個縮放比例（約 0.98）輸出，兩套的字級關係才會跟原稿一致。

## 要補其他月份時

來源 PNG（1640×2360、四周大片透明）丟給腳本即可，會自動算裁切線：

```bash
pip install Pillow
python3 tools/prep-calendar-title-images.py IMG_3620.png:6 IMG_3621.png:7
# 壓扁長條版的來源檔加 --slim，檔名會變成 title-MM-slim.webp
python3 tools/prep-calendar-title-images.py IMG_3630.png:1 --slim
```

參數格式是 `<來源檔>:<月份>`，輸出固定進 `images/calendar/`，來源檔不會被動到。
輸出高度改 `--height`（或腳本頂端的 `OUT_HEIGHT` / `SLIM_HEIGHT`）。
